# Trademark Policy / Politique de marque

## English

The source-code license does not grant rights to the Compendlore names, logos, visual identity,
official-release marks, or signing identities.

An artifact is an official Compendlore release only when it is published through a project-owned
channel and its manifest or signature can be verified with the project’s published release keys.
Official artifacts and signatures must not be altered or reused to endorse a modified build.

You may truthfully state that a project is based on, compatible with, or created for Compendlore,
provided the wording does not imply endorsement or official status. Forks, modified distributions,
and local builds must use a clearly distinct name and presentation and must state that they are
unofficial.

Community discussion, editorial reference, and non-commercial screenshots may use the project name
to identify Compendlore accurately. Uses that may cause confusion, impersonate the project, or imply
sponsorship require prior written permission from the project owner.

## Français

La licence du code source n’accorde aucun droit sur les noms Compendlore, les logos, l’identité
visuelle, les marques de versions officielles ou les identités de signature.

Un artefact constitue une version officielle de Compendlore uniquement lorsqu’il est publié par un
canal détenu par le projet et que son manifeste ou sa signature peut être vérifié avec les clés de
release publiées par le projet. Les artefacts et signatures officiels ne doivent pas être modifiés
ni réutilisés pour cautionner un build modifié.

Il est permis d’indiquer de façon exacte qu’un projet est basé sur Compendlore, compatible avec lui
ou créé pour lui, à condition que la formulation ne suggère ni approbation ni statut officiel. Les
forks, distributions modifiées et builds locaux doivent utiliser un nom et une présentation
clairement distincts et indiquer leur caractère non officiel.

Les discussions communautaires, références éditoriales et captures d’écran non commerciales peuvent
utiliser le nom du projet afin d’identifier Compendlore avec exactitude. Tout usage susceptible de
créer une confusion, d’usurper l’identité du projet ou de suggérer un parrainage exige
l’autorisation écrite préalable du propriétaire du projet.
